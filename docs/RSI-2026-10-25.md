# 用户验收修复：设置、随行伙伴、主题复用与多会话

依据用户提出的八项问题实施，不更新或替代用户的 75 分评价。

## 实现

- 设置使用固定高度、内容区滚动；七个标签切换时位置与高度一致。
- 模型连接参照用户的 lumen-utools 项目，使用连接列表和就地编辑；所有改动在外层统一保存，取消丢弃草稿。首页保留侧栏设置入口。
- 会话以 ID 维护独立的流、审批、控制器和消息。不同会话可同时执行，同一会话仍拒绝重复运行；停止只影响指定任务。偏好设置应用于后续任务，运行中的任务使用启动时的设置快照。
- Marp 主题支持作品详情直接套用、工作室下拉选择、Agent 查询 `list_marp_themes` 并以 `create_slides.themeId` 复用。使用 CSS 中真实的主题名称；演示保存 CSS 快照，原主题改名或删除不破坏已保存演示。
- DS 鲸鱼娘通过固定版本本地打包，44 种表情、8 组动作；保留作者及 CC BY-NC-SA 4.0 许可。人和 Agent 均能从内置目录选择。
- 人偶可切到随行模式，跨工作室、作品等页面显示；支持拖动、方向键移动、收起、位置记忆、跳回运行或待确认对话。真实任务状态优先于手动互动；鲸鱼娘根据思考、搜索、创作等状态使用对应表情。

## 验证

26 项 Node 集成/回归测试、TypeScript 检查和生产构建。新增测试覆盖双会话并行、同会话冲突、跨空间停止隔离、单独停止、运行时修改偏好、主题搜索与权限、改名后复用、CSS 快照及鲸鱼娘所有素材引用。

浏览器验证：1440 × 960 下七个设置页均为 820px 高；390 × 844 下测试页均为 793.36px 高。添加两个连接后仍只有一个 dialog，切换保留草稿，取消后恢复。实际渲染鲸鱼娘，验证互动、随行跨页和键盘移动。完成主题保存 → 作品详情套用 → 预览样式生效 → 保存演示。双会话使用隔离的本地模拟模型，确认切页后两者继续运行，停止 B 后 A 仍运行；不据此声称真实上游质量或长时负载已验证。

## 第二轮：用户问题 9–13

- Live2D 增加 `offsetX`，与缩放和垂直位置一起实时更新编辑预览、对话展台及随行人偶；旧人偶配置默认居中，导入导出保留水平位置。
- 外观使用独立预览草稿，全局界面和聊天示例随调整即时更新。保存持久化；取消、关闭或 Escape 恢复已保存外观。模型连接等配置仍通过外层保存提交。
- 三种皮肤：ORBIT 深空使用星轨 Canvas、悬浮导航及透明空间；FOLIO 纸页使用书刊衬线、平面导航和墨线输入框；VEIL 轻透使用柔光、岛屿导航及柔和几何。皮肤影响字体、导航、输入框、人偶展台和消息节奏。
- 支持背景文件与 HTTPS 图片地址、强度、模糊、对齐、气泡形态与圆角、密度、点缀色、明暗模式；皮肤可导出和导入。上传图片在浏览器缩小到最长边 1920px、转换 WebP 后随设置保存，不上传到第三方。Canvas 支持减少动态效果、后台暂停和 DPI 上限。
- AnySearch 使用官方 `POST https://api.anysearch.com/v1/search`，支持匿名或 Bearer 密钥，解析 `data.results`。错误不会把上游可能自动生成的凭据传入对话。保留 SearXNG 和 Tavily。
- 随行闲置时仅显示人偶；悬停或键盘聚焦显示控件。直接按住人偶拖动，5px 阈值区分点击和拖动，拖动不触发表情；支持方向键、边界约束、窗口缩放和位置记忆，触屏点击展开控件、点击外部收起。

验证：29 项测试、TypeScript、生产构建和格式检查通过。新增覆盖 AnySearch 匿名及密钥请求格式、嵌套结果、配额错误隐私、无效结果、旧配置默认值及背景格式。真实匿名查询返回 6 条结果；不据此声称已验证付费额度和所有限流情况。

浏览器使用实际鲸鱼娘验证：水平位置由 0 调到 0.10；深空/纸页/轻透切换；取消恢复；上传合成背景并调至 30% 强度、1px 模糊，刷新后保留；导出后切换皮肤再导入，恢复原配置；减少动态效果及 17px 气泡圆角即时生效。随行直接拖动从 (1176,520) 到 (966,610)，空闲容器透明、边框 0、控件隐藏，悬停控件可见。手机 390×844 下设置容器宽 354px、高 793.36px，无页面横向溢出。测试背景已移除。

### 星空皮肤非随行展台裁切修复

用户截图指出共事展台顶部名字、类型及状态被削掉。原因是 ORBIT 在启用 `overflow: hidden` 的完整展台上使用 `50%` 顶部圆角。改为 18px 容器圆角，拱形保留在独立的 `.stage-arch` 装饰层。浏览器验证 1440×960 和 1080×720 的非随行共事模式，顶部及切换人偶按钮完整；前端构建和 CSS 格式检查通过。证据：`images/orbit-docked-clipping-fixed.png`。
