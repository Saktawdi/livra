# Livra 设计与产品 RSI

用户反馈（2026-10-24）：字体模糊、交互缺少特点、模板化视觉与多余小字、细节不足。此前完成的功能不能代替产品质量，本轮重新建立验收标准。

## 定位

**有角色在场的个人 Agent 工作台。** 同一个人偶既可以陪你交流，也可以处理任务；同一段上下文可以从交谈走向作品。差异点必须体现在交互中：

1. **相伴 / 共事**：切换的是空间布局与实际使用的人偶能力。相伴扩大舞台，工作展开执行与作品；对话上下文保留。
2. **在场控制**：点击问候、目光跟随、语音口型、情绪可视、安静专注计时。全部有可感知状态和结束方式。
3. **结果就地展开**：工具产物可从执行记录打开预览并下载，不要求离开会话到作品列表寻找。
4. **快捷入口**：键盘搜索覆盖人偶、页面、历史；模型和角色选择支持键盘；常用功能在两步内可达。

## 设计语言

产品语言由「与人偶同桌」推导：人偶稳定在场，交流与执行连续，作品就地展开；纸面、窗形、信息层级、文案和动效共同服务这些行为。完整对应关系见 [产品理念](PRODUCT.md) 与 [设计体系](DESIGN.md)。

- 暖白工作面、石墨文字、朱砂强调；边界清楚，颜色承担状态意义，不堆叠渐变光晕。
- 中文使用系统无衬线字体，正文 16px / 1.75，操作 14px，次要信息 13px。仅非关键时间等允许 12px；不使用小于 12px 的字。正文不使用细衬线、不缩放文字、不在文字容器使用滤镜或 opacity。
- 统一 4px 间距网格、10 / 16px 圆角；少量 140–220ms 过渡，尊重减少动态设置。没有功能的星号、英文口号、页脚文案全部移除。
- 默认显示操作与结果；技术参数、帮助、工具 JSON 按需展开。

## 评分与结束门槛

各项按 0–5 打分再折算权重：0 缺失；1 只有草图；2 能走通但有明显缺陷；3 日常可用；4 多场景经过验收，细节完整；5 达到参照产品相同任务的成熟度，有完整证据。视觉、易用性分是内部审查，不冒充独立用户研究。

| 维度 | 权重 | 必须提供的证据 |
| --- | ---: | --- |
| 字体、可读性与可访问性 | 18 | 375 / 768 / 1440 布局，字号、对比度、焦点、键盘检查 |
| 产品定位与辨识度 | 14 | 相伴/共事差异、真实人偶状态、非模板空态 |
| 核心交互与任务效率 | 18 | 模型连接、切角色、发消息、审批、取消、作品预览全链路 |
| 视觉系统与构图 | 14 | 明暗、移动端、工作室、人偶编辑一致性截图 |
| 功能完整性与可靠性 | 16 | 协议、Agent、Fish、持久化、故障与恢复集成测试 |
| 细节、状态与动效 | 12 | 空/忙/错/取消/成功/加载、草稿保留、减少动态 |
| 自部署与工程质量 | 8 | 干净安装、生产构建、容器运行、备份与许可说明 |

结束需综合至少 90/100，且无 P0/P1 问题；字体与核心交互不低于各自权重的 90%。未通过的任务、缺失的真实供应商凭据与内部审查的局限必须公开。不得为了结束而调高分数；每次评分须连接截图、测试或具体操作记录。

## 迭代记录

### 基线

自评 48/100。可用的功能底座已有，但 UI 字号最小 7px，大量 8–11px 操作标签；重复文案、装饰占位、相伴/工作只切角色、作品需跳页。不能达到成熟产品标准。

### 第 1 轮：重新构建工作台

完成。替换样式体系，建立相伴/共事两种空间；同一会话可切换实际人偶，人偶舞台与执行区随之变化。统一字号、表单、焦点与弹窗；去掉装饰口号、星号和重复说明。工具产物可以在会话中打开。

首轮验收仍发现焦点落在关闭按钮、审批缺少写入正文、切页丢失草稿、多模型预览冲突等问题，因此未按完成界面直接判定达标。

### 第 2 轮：按任务验收修正

- 快速访问直接聚焦输入框；方向键与 Enter 可操作，退出恢复焦点。手机抽屉对隐藏内容设置 inert，并支持键盘退出。
- 审批展示待写记忆、生成描述或外部工具主机；失败回复可以带回输入框修改后重试。取消与断线保留部分回复。
- 会话、当前页面与人偶可在刷新后恢复；聊天草稿、工作室文字草稿和专注计时跨切页保留。
- 人偶库同时渲染一个实际预览，避免后台持续占用；修正 Pixi 共享纹理的清理方式。配置直达当前人偶，提供正确的模型预设与表情映射。
- 区分语音准备与真正播放；仅播放时以音频音量驱动口型。Fish 模拟服务验证 model 请求头、reference_id、语言和播放/停止。
- 已保存 Marp 主题可直接复用。实测发现自定义主题缺少基础字号，修为继承内置 default，再应用自定义 CSS；更新预览时显示忙碌状态。实测标题 46.4px，并保留主题配色。
- 容器验收发现无请求体的删除请求误带 JSON 类型头，已修复前端请求层。两种部署方式均通过冒烟检查。
- 将浅色时间文字对比度修为至少 4.55:1；统一所有演示导出按钮为实际执行的「导出 HTML」。

### 第 3 轮：生产与交付审查

在生产容器中重新打开干净空间，确认内置 Live2D 加载、模型连接入口、工作室编辑/保存、刷新保留草稿、作品库、快捷访问焦点与深色显示；此生产页没有控制台 error / warn。开发期间改动 hook 与重启服务产生的 HMR 日志没有作为生产通过证据。

本地检查结果：

| 验收 | 结果与证据 |
