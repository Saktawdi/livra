# Livra · 灵伴

## 产品理念：与人偶同桌

Livra 是一个有角色在场的个人 Agent 工作台。陪伴产生交流，交流形成任务，任务留下作品。用户始终知道谁在回应、正在做什么、留下了什么；模型、声音、形象和数据由用户选择。

「同桌」是产品的组织方式，而不是宣传语。人偶在桌边，对话位于桌面，执行记录和作品按需展开。人偶不是悬浮挂件，工具也不是另一个孤立产品。

## 为理念服务的设计语言

| 产品意图 | 视觉与信息组织 | 交互与行为 |
| --- | --- | --- |
| 有人在场 | 人偶有稳定的位置、姓名和可辨状态；舞台的窗形留白托住角色 | 点击问候、目光跟随、情绪表情、音频振幅口型；加载与失败如实显示 |
| 陪伴到协作是连续的 | 相伴保留完整舞台；共事收起舞台，展开执行与作品区 | 切换实际人格与工具能力，保留对话上下文；未完成任务时禁止切换 |
| 共同完成事情 | 作品紧邻对话和执行记录，工作室以画布为重心 | 产物就地打开、下载和复用；外部调用与写入按权限审批；运行可停止 |
| 安静、可长期使用 | 纸色背景承托画布与人偶；石墨正文；朱砂只强调当前操作与状态 | 高频操作直接出现，解释按需展开；键盘搜索、草稿保留、焦点恢复 |
| 人格可掌握 | 人偶资料统一人格、语言、声音、Live2D 与能力 | 自定义人物、记忆可查看编辑；没有隐蔽的记忆与工具授权 |
| 空间归用户所有 | 可选账号与自己的连接在同一层级 | 匿名 BYOK、可选 Sakta、Fish 与其他声音服务、本地导入导出、自部署 |

字体使用系统无衬线中文，正文 16px、操作 14px、辅助 13px，非关键时间最小 12px。去掉装饰英文、星号和重复说明。圆角与边界表达工作面的层级，避免所有内容都变成同样的卡片。动效用于确认状态和空间切换；尊重系统与应用内减少动态设置。

## 可验证的边界

- Live2D 内置官方示例用于开箱运行，不宣称它们是原创角色；可替换自有授权形象。
- 没有模型连接时，可以配置人偶、浏览工具和制作本地 Marp。真实推理需要 BYOK 或 Sakta。
- Fish 使用原生 TTS；当前收集有界音频后播放，没有声称实现实时双向语音或音色克隆。
- Agent 具备多轮工具循环、审批、取消、记忆和作品。当前是个人任务工作台，不包含任意代码执行沙箱与多人协作。
- 部分设置和编辑页尚未完成全部语言翻译；语言偏好和人偶回复语言可配置。
